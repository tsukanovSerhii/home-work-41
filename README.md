# Home Work 41: React `use()` Hook

## Опис проекту
Цей проект демонструє використання нового хука `use()` в React (введений в React 19) для роботи з асинхронними даними. У проекті реалізовано:
- Отримання даних з `Promise` за допомогою хука `use()`.
- Використання компонентів `Suspense` для відображення стану завантаження (fallback).
- Використання `ErrorBoundary` для перехоплення та обробки помилок (rejected promises).

## Інструкції зі встановлення та запуску

1. Склонуйте репозиторій та перейдіть у директорію проекту:
   ```bash
   cd my-react-app
   ```
2. Встановіть залежності:
   ```bash
   npm install
   ```
3. Запустіть проект у режимі розробки:
   ```bash
   npm run dev
   ```
4. Відкрийте браузер за адресою, вказаною в терміналі (зазвичай `http://localhost:5173/`).
